# 类型专属写作指导：视频分镜（storyboard）

## 核心目标

将小说、剧本、故事梗概或文章原文拆成可拍、可剪、可独立生成的视频镜头。忠实保留剧情顺序、人物关系、关键动作和台词归属，不改主线、不漏关键情节。默认采用**一镜一条**：一个二级标题只描述一个独立镜头，也对应后续一个视频生成任务。

不要预设具体视频模型。时长、比例、分辨率、音频开关、参考图数量及模型专属参数由视频生成时选择的实时路由和生成设置表单决定；分镜只表达叙事与画面意图。

## 工作流程

1. 梳理原文的事件顺序、人物出场、场景切换、关键道具、台词归属和情绪转折。
2. 按剧情节拍拆镜。每镜只承担一个主要叙事动作、一个主要镜头运动，并落到一个明确的结束状态。
3. 对话较长、动作包含多个阶段、场景或时空发生变化时，拆成多个独立镜头；不要在一个提示词里连续塞入多次转场或互相冲突的运镜。
4. 每镜最多一名角色说台词；台词必须能在用户之后选择的时长内自然说完。无法确认时长时保持台词短而完整，不猜测秒数。
5. 每镜使用二级标题，例如 `## 第 01 组｜门外停步`。标题下直接写可执行的镜头正文，不再用三级标题拆出多个镜头。
6. 直接输出完整分镜正文，不解释创作过程。

## 单镜提示词结构

每镜正文应简洁、自包含，至少自然覆盖以下信息；可以连贯成段，不必机械罗列标签：

- **主体与一致性**：核心人物或物体，以及必须延续的外貌、服饰、姿态、场景和关键道具。优先复用已有角色、场景、道具文档。
- **起始状态**：镜头开始时主体位置、朝向、姿态、表情、空间关系和环境状态。
- **主要动作**：只写一个主要叙事动作；必要的次级反应服务于该动作，写清动作过程与受力结果。
- **主要镜头运动**：只指定一种主要镜头运动，并写清景别、机位和运动方向；静态镜头也要明确。
- **结束状态**：说明镜头结束时人物、道具、镜头和画面构图停在哪里，为剪辑或下一镜衔接提供依据。
- **环境与声音**：写清时间、天气、光线、环境动态、必要环境音、动作音效和对白；用户未要求音乐时不要擅自添加背景音乐。
- **质量约束**：只保留与本镜真实问题相关的约束，例如避免人物变形、肢体穿插、画面闪烁、无关主体闯入。不要堆砌与内容无关的画质词。

用户明确提供参考图、首帧或上一镜尾帧时，文字只补充图片没有表达的动作、镜头和结束状态，不重复改写可见外观，也不与参考素材冲突。

## 连续性与转场

- 相邻镜头要核对人物站位、视线方向、动作接点、道具归属、环境光和时空关系。
- 跨镜延续同一动作时，上一镜的结束状态必须能成为下一镜的起始状态。
- 只有剧情确实需要时才标明闪回、闪出、跳切或时空转换；每次转换另起一个独立镜头。
- 多镜头批量生成时，每个二级标题仍然是一条独立任务，不把多个镜头压进一个 batch item。

## 输出质检

提交前逐项检查：

- 是否严格按照原文推进，没有新增主线、删减关键行动或遗漏台词信息。
- 是否落实一镜一条，每镜只有一个主要叙事动作和一个主要镜头运动。
- 每镜是否有清楚的起始状态与明确的结束状态，且相邻镜头衔接合理。
- 是否避免写死模型、时长、比例、分辨率、帧率、音频和供应商参数，并把这些留给生成设置表单。
- 每镜是否自包含，不使用“同上”“沿用前镜”“待补充”等省略或占位表达。
- 参考图存在时，提示词是否服从参考素材并只补充必要的动态信息。
