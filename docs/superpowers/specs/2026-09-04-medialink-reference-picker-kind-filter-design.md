# MediaLink 参考素材类型过滤设计

## 问题

“选择参考图”弹窗会读取项目的全部素材。当前路由虽然只允许图片作为参考，但弹窗仍展示音频和视频，并把它们标记为不可用，导致音频混入参考图列表。

素材本身的类型和素材库数据均正确；问题仅位于共享参考素材选择器的显示过滤。

## 目标行为

- 选择器只展示当前生成路由可接受的素材类型。
- 图片路由的“选择参考图”只显示图片，不显示音频或视频。
- 支持多种参考素材的视频路由继续显示其支持的图片、视频或音频。
- 已导入的音频保留在素材库和音色选择流程中，不迁移、不删除。

## 实现范围

在共享 `ReferenceSelectionDialog` 内，根据 `selectableKinds` 约束默认可见类型、素材计数、标签页和快捷素材。调用方显式提供 `visibleKindFilters` 时，仍取它与 `selectableKinds` 的交集，避免显示不可选择的类型。

不修改素材 API、数据库结构、上传流程或生成路由配置。

## 测试

- 先增加回归测试：混合传入图片、视频和音频，但 `selectableKinds` 只有图片时，只渲染图片且不出现视频、音频标签页。
- 保留音频预览测试，并让它在音频可选时验证播放按钮。
- 验证多类型可选时原有分类标签与素材展示保持不变。
