# MediaLink：AutoDL“检查连接即就绪”设计

日期：2026-09-01

状态：设计已确认，等待书面规格复审

关联规格：`2026-08-30-medialink-codex-autodl-design.md`、`2026-08-30-medialink-autodl-zimage-design.md`

本规格取代关联规格中“MediaLink 不自动启动 ComfyUI”和“测试连接只检查”的边界；不改变 AutoDL 实例仍由用户在云平台手动开机、关机和计费的边界。

## 目标

用户在 AutoDL 开机后只需更新 SSH 登录信息并点击“检查连接”。MediaLink 必须把指定实例推进到可以直接提交其已验证工作流的状态：SSH 可用、远程 ComfyUI/API 已运行、动态隧道已建立、健康检查通过、GPU 和工作流能力明确。

## 实例配置

每个实例在现有配置上增加：

- 可编辑的远程启动指令；由 MediaLink 初次接入时根据真实实例环境确认并填写。
- 启动等待超时和轮询状态；首版使用产品内安全默认值，不增加无必要的普通设置项。
- 可选高级本地端口；默认继续由系统自动分配，多个实例不得争用端口。

启动指令作为受信任的实例管理员配置保存，不从工作流 JSON、提示词或生成请求拼接。密码仍只进入 macOS Keychain。普通界面显示指令是否已配置；高级设置允许编辑。留空表示只连接和检查，不自动启动。

## 一键就绪流程

点击“检查连接”后严格执行：

1. 校验实例启用状态、SSH 字段、Keychain 密码和已确认 host fingerprint。
2. 建立 SSH 控制连接，并直接探测远程 loopback 上配置的 ComfyUI/API 端口。
3. 若服务已健康，跳过启动指令；不得重复启动。
4. 若端口未就绪且配置了启动指令，通过同一受控 SSH 连接执行一次启动指令。
5. 以条件轮询等待远程健康端点，不使用固定 sleep。超时后停止等待，但不主动杀死远程服务。
6. 健康后建立或复用动态本地 loopback 隧道。
7. 查询 `/system_stats`、`/object_info` 和 `/queue`，记录 ComfyUI 版本、GPU、节点和模型能力。
8. 重新验证该实例上的已启用工作流。只有必要的目标 workflow 验证通过，才显示“可以生成”。

生成任务发现实例尚未就绪时，可复用同一幂等 `EnsureReady` 流程；不得要求用户再次点击，也不得在故障时切换供应商或工作流。

## 多实例与并发

- 每个 `instanceProfileId` 独立维护就绪操作、隧道和状态。
- 同一实例的并发检查合并为一次操作；不同实例可以并行。
- SSH 地址、远程端口、fingerprint 或启动指令变化时，使旧连接和相关 readiness 失效并重新检查。
- 本地端口默认自动分配；高级手动端口冲突时明确失败，不回退到另一个不可见端口。
- H3、生图以及未来合并到同一实例的工作流共用该连接层，不在启动器中写死模型名称。

## 状态与错误

界面按阶段展示：`连接 SSH`、`检查远程服务`、`启动服务`、`等待健康`、`建立隧道`、`验证 GPU/API`、`验证工作流`、`可以生成`。

错误必须包含稳定阶段和可操作原因，至少区分：实例未开机、密码缺失、host key 未确认或变化、SSH 认证失败、启动指令缺失或退出失败、健康检查超时、端口冲突、GPU/API 异常、节点/模型/工作流不兼容。HTTP 层不得再把这些已知错误只显示为 `internal error`。

## 安全与生命周期

- 启动指令不得进入命令行日志、生成任务或前端遥测；密码不得作为远程命令参数。
- 不提供任意提示词驱动的远程命令执行入口。
- MediaLink 退出时关闭本地隧道，但不停止远程 ComfyUI；AutoDL 关机仍由用户控制。
- 已健康的服务不重启；启动失败不循环执行指令。用户再次点击检查时才可开始新一次启动尝试。
- 不暂停或修改 ComfyUIPhotoSync 等归档服务。

## 测试与验收

- fake SSH/远程端口测试服务已运行时跳过启动、未运行时只启动一次、启动失败、健康超时和并发合并。
- 测试动态端口、多实例并行、手动端口冲突以及连接字段变化后的失效重建。
- 测试每个已知错误映射为具体用户消息，密码和启动输出不泄露。
- 测试生成任务可复用 `EnsureReady`，且不会重复提交 ComfyUI `/prompt`。
- 真实实例验收仅执行连接、启动与健康检查，不运行工作流。确认“可以生成”后，真实生图或视频仍需遵守各自的单独验收边界。

## 完成标准

AutoDL 实例已由用户开机且 SSH 配置正确时，点击一次“检查连接”即可让对应 ComfyUI/API 自动启动并进入可生成状态。重复检查幂等，多实例互不串号，端口不写死，错误具体可操作，无需用户打开终端或手动运行启动脚本。
